https://github.com/huggingface/smollm  The Hugging Face SmolLM repository collects efficient, lightweight models meant to run on local devices, including text language models and multimodal vision models. The project publishes model weights along with the data mixtures and training configurations behind them. It also covers multilingual support and reasoning features designed to run without industrial-scale hardware.

https://github.com/huggingface/smol-course  The smol-course is a community-run course from Hugging Face that teaches how to align and fine-tune small language models. It uses efficient models such as SmolLM3 and covers instruction tuning, preference alignment, and synthetic data generation on ordinary local hardware. The modules run from first training steps to production deployment. The course presents small-model benefits: privacy, lower operating costs, and reduced environmental impact. It is an entry point for researchers and engineers building custom, domain-specific AI through hands-on exercises with peer review.
